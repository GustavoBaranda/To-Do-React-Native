## 📖 Sobre el Proyecto

Aplicación móvil nativa para la gestión de tareas diarias (**To-Do App**) desarrollada con **React Native** y **Expo** para iOS y Android.

La aplicación permite a los usuarios agregar tareas con fecha y hora personalizada mediante picker nativo, marcar ítems pendientes o completados, filtrarlos e interactuar mediante modales interactivos de confirmación y navegación por pestañas (*Bottom Tabs*).

---

## ✨ Características Principales

- 📝 **Gestión de Tareas:** Alta, edición, estado (pendiente / completada) y eliminación de tareas.
- 📅 **Selector de Fecha y Hora:** Integración con `@react-native-community/datetimepicker`.
- 🗂️ **Listados Optimizados:** Uso de `FlatList` nativo para scroll fluido y alto rendimiento.
- 📱 **Navegación por Pestañas:** Navegación fluida entre pantallas mediante `@react-navigation/bottom-tabs`.
- 🎨 **Componentes Modulares & Reutilizables:** Modales de confirmación personalizados, inputs estilizados, cards de tareas y botones dinámicos.
- 🚀 **Multiplataforma:** Compatible con Android, iOS y Web mediante **Expo CLI**.

## 🚀 Instalación y Ejecución

```bash
# 1. Clonar el repositorio
git clone https://github.com/GustavoBaranda/To-Do-React-Native.git
cd To-Do-React-Native

# 2. Instalar dependencias
npm install

# 3. Iniciar con Expo CLI
npx expo start
```

> Escaneá el código QR generado en la consola desde la app **Expo Go** en tu dispositivo físico (Android o iOS) o iniciá un emulador local.
